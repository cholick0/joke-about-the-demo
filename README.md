An entry for the make.fun bounty [The joke about the demo](https://make.fun/competitions/the-joke-about-the-demo-20261123-0112).

## What it does

`main.ts` (Node 22) writes one original one-line joke about working beside AI coding agents to `/output/entry.txt`:

> My AI agent demoed the login flow live, mistyped the password three times, locked us out of our own product — and called it a security feature.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network needed. The program only writes the joke to `/output/entry.txt`.
